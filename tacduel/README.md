# Tactical Duel ⚔

Тактическая дуэль 1v1 для Android.

## Как получить APK через GitHub (бесплатно, ~7 минут)

### Шаг 1: Загрузи на GitHub
1. Зайди на **github.com** → войди в аккаунт
2. Нажми **"+"** → **"New repository"**
3. Название: `tactical-duel`
4. Нажми **"Create repository"**
5. Нажми **"Upload files"** и перетащи **все файлы** из этой папки
6. Нажми **"Commit changes"**

### Шаг 2: Дождись сборки
1. Перейди во вкладку **"Actions"**
2. Увидишь запущенный процесс `Build APK` — подожди ~7 минут
3. Когда появится зелёная галочка ✅ — нажми на него

### Шаг 3: Скачай APK
1. Внизу страницы раздел **"Artifacts"**
2. Нажми **"tactical-duel-debug"**
3. Скачай ZIP → распакуй → получишь `app-debug.apk`

### Установка на телефон
- Разреши установку из неизвестных источников в настройках
- Открой APK файл — установится как обычное приложение

## Возможности игры

- ⚔ **6 уникальных персонажей** с пассивными способностями
- 🗺 **5 арен**: Классика, Руины, Река, Вулкан, Лабиринт
- 🤖 **Режим vs Бот** — полноценный тактический ИИ
- 📱 **Один телефон** — передаёте по очереди
- 📡 **WiFi мультиплеер** — два телефона в одной сети
- 🎨 **4 темы** + настраиваемые токены
- 🎮 **Статистика**, правила, настройки

## Персонажи

| Герой | HP | Щит | Особенность |
|-------|-----|------|-------------|
| 🛡 Рыцарь | 100 | 80 | Щит восстанавливается +5 каждые 2 раунда |
| 🏹 Лучник | 85 | 50 | Урон лука +5, слабый только на 1 клетке |
| 🗡 Разбойник | 80 | 40 | 3 действия за ход, 3 бомбы |
| 🔮 Маг | 75 | 30 | 3 бомбы, урон 30, двойной взрыв |
| ⚔ Берсерк | 110 | — | Меч 25, ярость ×1.5 после урона |
| ⚙ Инженер | 90 | 60 | 4 бомбы, дальность броска 8 клеток |

## Правила кратко

- **2 действия** за полуход (Разбойник — 3)
- **Меч**: радиус 1, мгновенный урон
- **Лук**: по 8 линиям, летит **после хода противника**
- **Бомба**: бросок до 6 клеток, взрыв по рандомной линии
- **Щит**: 50 прочности, блокирует весь урон раунда
